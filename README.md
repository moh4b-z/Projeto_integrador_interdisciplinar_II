# Base de Dados - history.

A Terra Signal é uma empresa fictícia do setor
de telecomunicações. A base history.csv,
disponibilizada pela Databricks, contém
informações sobre sua carteira histórica de clientes,
incluindo características individuals, serviços
contratados, relacionamento, informações financeiras
e histórico de cancelamento.

---

Este projeto investiga os motivos que levam os clientes da Terra Signal a cancelarem seus serviços (churn). Para isso, a análise cruza três frentes principais: o perfil demográfico e contratual do usuário, o impacto financeiro dessas perdas na receita da empresa, e a análise do feedback dos clientes para entender a verdadeira experiência por trás das insatisfações. O objetivo final é criar uma análise de risco robusta, capaz de identificar padrões de clientes propensos a deixar a operadora e fornecer insights acionáveis para retenção

Vamos fazer uma analise de risco da pessoa, para verificar se ela vai ser um bom cliente,analisando se tem esposo(a), dependente,sao idosos , opinioes,creditos, feedback
